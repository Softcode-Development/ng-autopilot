# Internationalisation

The project's i18n library, locales, file layout and source-of-truth locale are named in the project's `docs/ARCHITECTURE.md` (§ i18n). These rules hold for any library.

- **No hardcoded user-facing strings** in templates or TypeScript — every visible string is a translation key. — **Enforcement:** lint `autopilot/template-no-hardcoded-text` (static text, untranslated literals in interpolations, `placeholder`/`title`/`alt`/`aria-label`/`label` attributes — external and inline templates); TypeScript strings: review.
- **Every locale mirrors its source file** — same keys, no empty values, the same interpolation parameters. — **Enforcement:** `tools/autopilot/i18n/i18n-validate.mjs` (lint-staged on locale files, and the final gate).
- **No unused keys.** — **Enforcement:** `tools/autopilot/i18n/i18n-unused.mjs` (final gate); keys built dynamically are listed under `i18n.ignoreUnusedPrefixes`.
- **Keys follow `feature.section.key`** (e.g. `transactions.fast_add.amount_label`).
- **Every key is added to every locale in the same change.** A missing translation fails CI. Translations are real, hand-maintained text — never machine-regenerated over existing entries.
- **Bind a precomputed key**, never build a key inline in the template (template purity).
- **Enums:** an `as const` map + a `Record<Enum, string>` of i18n keys, exposed as a component property and piped through the translate pipe in the template — never a precomputed map of translated labels, so runtime locale switching keeps working.
- **Numbers, dates and currencies** render through locale-aware pipes or formatters, never string concatenation.
- **Plurals and interpolation** use the library's ICU/plural support, not `if` branches in templates.
- **The backend returns keys or codes, not localised text**; the frontend translates (emails rendered server-side are the usual exception).
- **Brand and identity strings** (product name, legal entity) live in config, not in translation files; translation files hold only locale-dependent words.
- **Generated copies are never edited** — if translation files are mirrored into `public/`/`assets/` by a script, edit the source.
